# Flask проект

Практическая работа №1 по созданию многостраничного приложения на Flask.

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

После запуска доступны страницы:

- `http://127.0.0.1:5000/`
- `http://127.0.0.1:5000/about`
- `http://127.0.0.1:5000/changelog`
